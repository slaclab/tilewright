# How to publish a dataset

Publishing a dataset is the job of the onboarding skill that ships with `tilewright`. It
holds the walkthrough, the source and identity guides, the dataset YAML reference and the
example YAMLs, for an agent and for a person alike.

```bash
tilewright skills install     # once: links the skill into ~/.claude/skills/
```

Then open Claude Code in your data root and type `/onboarding`. To do it by hand, read
[the walkthrough](https://github.com/slaclab/tilewright/blob/main/skills/onboarding/reference/walkthrough.md);
the headings below keep the old links to this page working.
